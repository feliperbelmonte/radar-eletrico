# Resposta — quando a empresa responde

Contexto geral, painel e ciclo de aprendizado: skill `prospeccao-funil`.

## Princípios

- Responder rápido (no mesmo dia), curto e no mesmo tom da pessoa. É conversa de WhatsApp, não e-mail.
- O objetivo da primeira resposta não é vender: é marcar o próximo passo (entender a demanda, ver um projeto, uma ligação rápida).
- Felipe faz **só projeto**: nunca sugerir que ele execute obra. Deixar claro que não concorre com a execução quando isso ajudar.
- Nunca inventar portfólio, prazo, preço ou experiência que o Felipe não confirmou. Se faltar informação, perguntar a ele antes de rascunhar.
- Ao rascunhar, entregar o texto pronto para colar, com no máximo 2 variações curtas.
- Atualizar o status no painel: respondeu com interesse → "Respondeu"; pediu para parar ou não tem interesse → "Sem interesse"; e uma anotação curta do que foi dito (sem dados pessoais desnecessários).

## Situações comuns (ponto de partida, ajustar com as lições)

- **"Tenho interesse" / "Manda mais informações"**: agradecer, perguntar que tipo de projeto eles mais têm (residencial, comercial, industrial, SPDA, subestação, solar) e como fazem hoje. Passa para `prospeccao-qualificacao`.
- **"Quanto custa?"**: o preço depende do projeto; pedir os dados mínimos (tipo, área ou carga, cidade, prazo) para orçar. Se ele quiser dar uma faixa, só com valores que o Felipe definiu (ver `prospeccao-proposta`).
- **"Já temos engenheiro"**: tudo certo; oferecer-se como apoio para picos de demanda ou para o que o engenheiro deles não faz (ex.: SPDA, subestação, laudos). Deixar o contato e encerrar com leveza.
- **"Manda portfólio / currículo"**: usar só o material que o Felipe tiver; se não houver, oferecer descrever projetos já feitos (com autorização dele) ou fazer um primeiro projeto pequeno.
- **Resposta seca ("quem é?", "?")**: reapresentar em uma linha, com a oferta e a pergunta.
- **"Não tenho interesse" / "Pare"**: agradecer, encerrar, marcar "Sem interesse". Não insistir.
- **Pedido só de "assinatura de ART" sem fazer o projeto**: recusar com educação — assinar responsabilidade técnica sem ter feito ou acompanhado o trabalho é acobertamento, infração ética no Sistema CONFEA/CREA. Oferecer fazer o projeto de fato.
