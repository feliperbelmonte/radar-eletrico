# Qualificação — "respondeu" → "qualificado" ou "sem interesse"

Contexto geral, painel e ciclo de aprendizado: skill `prospeccao-funil`.

## O que descobrir (aos poucos, em conversa, não como questionário)

1. **Tipo de projeto**: residencial, comercial, industrial, SPDA, laudo/NR-10, subestação, solar, regularização/as built.
2. **Volume**: um projeto pontual ou demanda recorrente (quantos por mês)?
3. **Como fazem hoje**: engenheiro próprio, outro terceirizado, ninguém (e como resolvem a ART)?
4. **Onde são as obras**: PR (ART direta) ou outro estado (confirmar a exigência do CREA local antes de aceitar).
5. **Prazo** e **quem decide** a contratação.
6. **Informações disponíveis**: planta de arquitetura, cargas, padrão de entrada da concessionária, fotos/levantamento.

## Critérios

- **Bom encaixe**: projeto que o Felipe faz, obra no PR (ou fora com a exigência resolvida), prazo viável, perspectiva de repetir.
- **Atenção**: prazo muito curto, escopo vago, cliente que só fala de preço, obra em outro estado sem visto.
- **Não seguir**: pedido para só assinar ART sem fazer o projeto (acobertamento, infração ética), pedido de execução de obra, escopo fora da área dele.

Qualificou → status "Qualificado" no painel, com uma anotação: tipo de projeto, volume, prazo. Passa para `prospeccao-proposta`.
Não encaixa → "Sem interesse" com o motivo na anotação (isso alimenta as lições).
